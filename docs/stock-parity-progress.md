The audit describes baseline `af65396`; it is not a claim that all listed gaps
have been repaired. Changes below remain uncommitted pending review.

All remaining C1–C14, N1–N4, G1–G4, M1–M4 and S1–S3 scope stays open
unless explicitly covered above. In particular, this is not a completed Siege,
ICARUS, ROFF, holdable, vehicle or pure-server implementation.

Evidence was produced on Linux on 2026-10-05 against OpenJK
`1a6a643427aa347553e9073dac5570b33337c4d9`, using synthetic inputs and unchanged
reference functions. Rendering checks read installed assets in place. No populated
servers, audible client tests, owner launcher changes, publication, retail-data
copies or protocol-codec edits were involved.

An external offscreen viewer harness on Radeon RX 9060 XT / RADV Vulkan loads
FFA3 at 1280×720 and injects shield, beam and concussion entities into the production
presentation paths. GPU expansion and CPU fallback both pass without validation
errors; shields/beam affect the same 40,570 pixels and screen bounds in paired
presence/absence captures. Animated shader phases differ between runs. This
checks rendering, not network delivery or the complete gameplay lifecycle.
The harness opens no window or audio device. Effect blend-slot storage is now
reserved at map installation, so the first special entity does not grow it in-frame.

Final Linux checks pass: `cargo fmt --all --check`,
`cargo build --locked --workspace`, `cargo test --locked --workspace` (27 tests)
and `git diff --check`. Documentation file links were checked. No bundled test
infrastructure was added; external scratch reports were removed after verification.
Windows, audible output, populated-game performance and a complete native/legacy
multiplayer playtest remain unverified. The owner launcher still selects the
previous build.

A release-mode synthetic CPU frame with 31 animation cursors, 16 shield faces,
six beams and speaker/timer updates measured 0.00123 ms median / 0.00145 ms p99,
with zero heap allocations across 20,000 frames on Ryzen 5 5500. This is
adapter-only cost, not a full renderer or 31-player game benchmark.
